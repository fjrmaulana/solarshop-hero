# Solar Shop — Hero section concept

Hero section redesign for solarshop.co.nz: "Reliable solar solutions from a trusted brand", with the tagline "Powered by Trilect".

- `index.html`: hero markup (the header is a recreation of the existing site header, for context only)
- `css/hero.css`: all colours, fonts and spacing as CSS variables at the top, so global changes are one edit
- `assets/img/solarshop-powered-by-trilect.png`: logo lockup exactly as supplied
- `assets/img/trilect-team.jpg`: team photo as supplied
- `assets/fonts/`: Plus Jakarta Sans and Fraunces (SIL Open Font License)

## Sizes
- Desktop hero: 360 px tall (about one third of the current hero)
- Tablet: two columns, info cards in a row below
- Mobile: stacked, full-width buttons

## Importing into Figma
Use the free "html.to.design" Figma plugin and paste the live preview URL. It imports the page as editable Figma layers (text, frames, colours).

## Publish (GitHub Pages)
Push to a public repo, then Settings › Pages › Deploy from a branch › main / (root).
